# CLVCH Brand Guidelines

## Brand Name
- Full: CLVCH
- Tagline: Bites. Beats. Booze.
- Pronunciation: "Clutch"

## Colors
| Name | Hex | Usage |
|---|---|---|
| Ink (Background) | #0a0a0a | Primary background, dark surfaces |
| Bone (White) | #ffffff | Primary text, headings, CTAs |
| Bone Dim | #b0b0a8 | Secondary text, descriptions |
| Bone Muted | #6b6b63 | Tertiary text, disclaimers, labels |
| Line | rgba(255,255,255,0.18) | Borders, dividers |
| Line Soft | rgba(255,255,255,0.09) | Subtle dividers |
| Error Red | #ff8b7e | Error messages, validation |

## Typography
| Font | Usage | Where to Get |
|---|---|---|
| Bebas Neue | Display headings, large text, CTAs | Google Fonts (free) |
| Cormorant Garamond | Editorial, italic accents, subheadings | Google Fonts (free) |
| JetBrains Mono | Mono text, labels, disclaimers, eyebrows | Google Fonts (free) |

### Usage Rules
- Headings: Bebas Neue, uppercase, tight letter-spacing
- Body/subcopy: Cormorant Garamond, normal weight, generous line-height
- Labels/eyebrows/disclaimers: JetBrains Mono, uppercase, wide letter-spacing (0.12-0.22em)
- Italic accent text: Cormorant Garamond italic (used for emphasis in headings)

## Design Rules
- Border radius: 0 everywhere (hard edges, no rounded corners — brand rule)
- Aesthetic: Dark luxury, minimal, premium
- Less is more — white space is intentional
- No gradients, no shadows, no decorative elements

## Logo Files
- Primary: White logo on black/dark background
- Add logo files to brand/logos/ folder
- Minimum clear space: logo height on all sides
- Never stretch, rotate, or recolor the logo

## Brand Voice
- Premium but not pretentious
- Confident, not loud
- Insider language ("the floor", "the list", "first-call access")
- Short sentences, punchy copy
- Sports energy meets nightlife sophistication

## Key Phrases (Use in Content)
- "Bites. Beats. Booze."
- "The List" (VIP email list)
- "The Floor" (the venue experience)
- "Step inside"
- "First access"
- "See you on the floor"
